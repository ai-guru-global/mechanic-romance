# 发布与推广 · Go-to-Market

> 一句话：求职线现在就能用，社区线等可信度门禁全绿再启动。

---

## 定位

本项目对外传播分两条线，各有一句话定位：

**求职线（招聘方 / 面试官 / 猎头）**

> 把具身智能研究组织成可复现、可讲解语料库的独立研究项目。卖点是研究组织力与诚实标注——「待核实」就标待核实，设计文档就明说是设计文档。

**社区线（开源社区）**

> 中文最系统的具身智能研究语料库 + Demo 场景工作台。卖点是可检索、互链、统一模板——看完即懂，讲完即用。

两条线共用同一个仓库，但启动时机不同：求职线现在可用，社区线等 [可信度门禁](#可信度门禁) 全部达成。

---

## 时机判断

### 求职线为什么现在可用

- P0 可信度问题已基本修复：绝大多数笔记已补参考节（仿真平台类笔记待补）、README 与 roadmap 里程碑状态一致、死链已清理（2026-09 上旬系列提交，见 git log）。
- 语料 + 场景定义足以展示研究组织能力——求职评估看的是「怎么组织知识」，不是「代码能不能跑」。
- 定位诚实：仓库当前就是设计文档 + 语料库，简历与面试如实说明，经得起追问。

### 社区线为什么等 M3

- 开源社区的第一印象只有一次：「0 行代码」在大流量渠道容易被定性为 PPT 项目。
- 首个可跑复现（[docs/roadmap.md](../docs/roadmap.md) M3）是最小可信度证明——「说到的能跑」比「写得多」值钱。
- 门禁未过就投大流量渠道，印象成本不可逆。

### 时机表

| 阶段 | 该做什么 | 面向谁 |
| --- | --- | --- |
| 现在（2026-09，M2 进行中） | 求职线全开：简历项目条目、面试讲解、猎头一页纸 | 招聘方 / 面试官 / 猎头 |
| M2 收尾 | 求职线继续；私下半公开——把仓库链接直接发给感兴趣的同行，不发公开帖 | 一对一接触的同行 |
| M3 落地 | 可信度门禁清零后，社区首发帖 | 开源社区 |
| M4 完成 | Demo 视频 / 阶段报告产出后二次传播 | 全受众 |

### 反模式

- ❌ 门禁未过就投掘金 / V2EX 等大流量渠道——开源社区的一次性印象成本不可逆。
- ❌ 简历 / 面试吹「场景都能跑」——一问代码就露馅；诚实定位反而加分。
- ❌ 等「全部做完」才求职——求职线不依赖 M3，语料库本身就是交付物。

## 渠道与动作

### 求职线（现在激活）

**简历项目栏话术**（一句话 + 仓库链接 + 状态标签，篇数不写死、以仓库 README「30 秒读懂」为准）：

> 具身智能研究语料库「机械浪漫」：方法 / 硬件 / 仿真 / 概念多主题研究笔记 + 8 大类 Demo 场景设计文档，统一写作与引用规范（github.com/allengaller/mechanic-romance）｜状态：语料库完成，场景复现进行中

**面试 STAR 要点**：

- **S / T（为什么做）**：论文在 arXiv、代码在 GitHub、笔记在 Notion，三岛割裂，研究知识无法检索与复用。
- **A（怎么组织）**：统一场景模板（任务 / 观测 / 评估 / 硬件齐备）、统一引用规范（BibTeX + 来源 URL + 访问日期，见 [docs/conventions.md](../docs/conventions.md)）、诚实标注（待核实条目明示、场景状态透明）。
- **R（结果）**：规模与进度以根 README「[30 秒读懂](../README.md#30-秒读懂)」与 [docs/roadmap.md](../docs/roadmap.md) 为准——面试时打开仓库现场讲，不背数字。

**猎头 / 内部转岗一页纸**：直接引用本页「定位」一节的两句话 + 仓库链接。

### 社区线（门禁通过后激活）

**渠道清单**（附各自适配的内容形态）：

| 渠道 | 适配内容形态 |
| --- | --- |
| 掘金 | 首发长文：完整讲清痛点 + 结构 + 场景表 |
| 知乎 | 长文 + 「如何评价具身智能语料库」类回答引流 |
| V2EX | 分享创造节点短帖：链接 + 三句话价值主张 |
| LeRobot Discord | 英文短介绍 + 具体场景链接，垂直受众 |

**首发帖结构**：

1. 痛点：论文、代码、笔记三岛割裂；
2. 是什么：可检索语料库 + 场景工作台，配知识地图截图；
3. 场景全景：引用根 README 的 8 场景表，不复制；
4. 诚实说明：当前状态、roadmap、门禁剩余项；
5. 求反馈：明确问「哪里最值得先做」。

> 凡涉及「几点发帖曝光最好」之类的发布时间窗口经验断言，一律标注「（经验推测，待核实）」后再写。
