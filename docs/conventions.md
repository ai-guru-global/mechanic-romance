# 写作规范 · Conventions

> 本文件是「机械浪漫」语料库的统一写作约定，保证内容风格一致、可检索、可复用。

---

## 1. Markdown 规范

- 使用 **GitHub Flavored Markdown (GFM)**。
- 标题层级：`#` 文件标题，`##` 章节，`###` 子章节，正文不跳级。
- 代码块标注语言：```` ```python ````、```` ```bibtex ````、```` ```bash ````。
- 数学公式：行内 `$...$`，独占行 `$$...$$`。
- 表格用 Markdown 表格语法，长表格考虑拆分。

---

## 2. 命名规范

| 对象 | 规则 | 示例 |
| --- | --- | --- |
| 论文笔记 | `年份-首作者-关键词.md` | `2023-brohan-rt2.md` |
| 方法笔记 | `方法英文名.md`（小写连字符） | `diffusion-policy.md` |
| 数据集 | `数据集英文名.md`（小写） | `open-x-embodiment.md` |
| 实验 | `YYYY-MM-DD-关键词.md` | `2026-08-05-dp-ablation.md` |
| 场景目录 | `NN-中文场景名/` | `01-桌面抓取/` |
| 图片 | `kebab-case.png` 放对应 `assets/` | `task-overview.png` |

> 原则：**目录与脚本名用英文连字符**，笔记标题可用中文。

---

## 3. 引用规范

- 每篇论文笔记顶部放 **BibTeX 代码块**。
- 正文用 `[@citekey]` 行内引用。
- 引用网页注明 URL + 访问日期：`（来源：example.com，访问于 2026-08-02）`。
- 引用图片/视频标注来源与许可。

---

## 4. 笔记结构模板

一篇合格的研究笔记建议包含：

```markdown
# 标题（中文 · English Title）

> 一句话概括。

## 元信息
- 作者 / 机构 / 年份 / 会议
- 论文链接 / 代码链接

## BibTeX
（代码块）

## 核心问题
这篇要解决什么问题？为什么重要？

## 方法
关键思路、公式、图示。

## 实验
数据集、基线、指标、关键结果。

## 个人评价
优点 / 局限 / 与本研究的关系。
```

## 5. 术语表

首次出现的术语建议「中文（English）」并列，后续可只用其一。常见术语集中在 `corpus/` 各 README 的术语小节维护。
