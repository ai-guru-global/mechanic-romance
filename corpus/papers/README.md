# 论文笔记 · Papers

收录具身智能相关论文的阅读笔记。**按主题建子目录**，每篇论文一个 `.md`。

---

## 建议的子目录

```
papers/
├── manipulation/     # 操作：抓取、装配、灵巧手
├── navigation/       # 导航：移动、建图、避障
├── foundation/       # 基础模型：VLA、大模型驱动具身
├── learning/         # 学习范式：IL / RL / 离线 RL / Sim-to-Real
└── ...               # 按需扩展
```

> 子目录可随研究推进新建，命名用英文小写连字符。

---

## 文件命名

`年份-首作者-关键词.md`，例如：

- `2023-brohan-rt2.md`
- `2023-chi-diffusion-policy.md`
- `2024-octo-generalist.md`
