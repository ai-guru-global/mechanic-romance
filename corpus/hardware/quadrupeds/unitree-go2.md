## 3. 关键技术

### 3.1 自研运控

- **强化学习训练**（Isaac Lab）
- **域随机化** Sim-to-Real
- **12-DoF 全身协调**

```
仿真（Isaac Lab + PPO）→ 域随机化 → Sim-to-Real → 部署
```

### 3.2 自研 LiDAR

- **360° 2D / 3D LiDAR**（自研）
- 探测距离：30-50 m
- 角分辨率：0.5°
- 替代外购 Velodyne（降本）

### 3.3 VLA 集成（旗舰版）

**Go2 旗舰内置 4B 参数 VLA 模型**：

- 视觉 + 语音 → VLA → 动作
- 基础任务：跟随、避障、识别
- **可二次开发**（Python SDK）

### 3.4 SDK / API

- **Python SDK** 完整
- **ROS2** 集成
- **App 控制**（iOS / Android）
- **Web 远程**（RTSP 视频流）

## 8. 优势与挑战

### 8.1 优势

- **价格屠夫**（$1.6k 起）
- **VLA 内置**（旗舰版）
- **量产能力强**
- **SDK 完整**（Python / ROS2）
- **续航长**（2-4 h）

### 8.2 挑战

- **算法不及 Spot**（运控稳定性）
- **服务不足**（海外）
- **AI 路线激进**（VLA 早期）
- **品牌仍弱**（vs Boston Dynamics）
