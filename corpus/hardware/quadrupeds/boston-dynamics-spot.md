## 3. 关键技术

### 3.1 运控算法（30 年积累）

```
动力学模型（MIT 系列）
    ↓
模型预测控制（MPC）
    ↓
全身协调（12-DoF）
    ↓
步态生成（trot / crawl / 跳跃）
    ↓
Sim-to-Real（深度学习 + 域随机化）
```

| 能力 | 描述 |
| --- | --- |
| **复杂地形** | 楼梯 / 斜坡 / 碎石 / 雪地 |
| **摔倒恢复** | 自动起身（被踢 / 推倒） |
| **自主导航** | SLAM + 全局规划 |
| **群体** | 多 Spot 协同（Spot CAM） |
| **API 完整** | Python / C++ / ROS2 |

### 3.2 自主导航

- **SLAM**：Visual-Inertial + LiDAR（部分型号）
- **路径规划**：A* / RRT*
- **避障**：实时立体视觉
- **Mission Editor**：可视化任务编排
- **Orbit 平台**：云端多机管理

### 3.3 Spot Arm（带臂版）

- 7-DoF 机械臂
- 平行夹爪 + 可换工具
- 典型任务：开关阀门、捡垃圾、推门、按按钮

## 9. 优势与挑战

### 9.1 优势

- **算法积累最深**（30 年）
- **稳定性极佳**（户外极端环境）
- **SDK 完整**（Python / C++ / ROS2）
- **品牌效应**（行业标杆）
- **售后体系**（Hyundai 资源）

### 9.2 挑战

- **价格高**（$75k+ 与 Go2 50× 差距）
- **销量不及宇树**（$1.6k Go2 数万台）
- **AI 范式保守**（传统控制，非 VLA）
- **中国市场弱**（宇树主场）
