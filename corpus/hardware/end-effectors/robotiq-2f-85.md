# Robotiq 2F-85 自适应两指夹爪

> **一句话定位**：加拿大 Robotiq 公司的**自适应（adaptive）两指平行夹爪**——指段可被动铰接、自动包络物体形状，85 mm 行程、5 kg 负载、20–235 N 抓取力，是 UR / Franka 等协作与研究机械臂上**最普及的末端执行器之一**，以「即插即用 + 自适应指」著称。

> 最后更新：2026-08

---

## 1. 概览

Robotiq 2F-85 是 Robotiq「2F 系列」（2F-85 / 2F-140）中的**标准行程款**，与较大行程的 2F-140 共享同一驱动模组与控制接口，仅指段长度与行程不同。它是为协作机器人（尤其 UR 系列）设计的「**装上就能用**」夹爪：

- **自适应指（adaptive fingers）**：每根指分两段，靠机构被动铰接，夹持时会自动包络（envelope）物体，对形状/尺寸变化鲁棒——这是它区别于普通刚性平行夹爪的核心。
- **电动驱动**：内置无刷电机 + 丝杠，无需气源（对比气动夹爪），适合无气源的实验室/轻型产线。
- **多模式抓取**：支持基本/宽行程/夹持（钳式）/剪刀四种模式，靠更换指段安装方向实现。

定位：**研究级「万能夹爪」**——不是最精、最强、最快，但在「通用性 + 易用性 + 与主流机械臂兼容」上综合最优，因此成为 IL/BC 实验的默认末端执行器。

> 「2F」= Two Finger；「85」= 85 mm 最大行程。

| 参数（Parameter） | 数值（Value） | 备注 |
| --- | --- | --- |

| 抓取力 Grip Force | **20–235 N**（可调） | 分档可设 |
| 抓取力档位 | 通常 3–4 档（如 30/90/200 N 量级） | 实际取决于固件/接口 |
| 重复精度 Repeatability | 约 ±0.05 mm（量级） | 指尖位置 |
| 供电 | 24 V DC | 机械臂末端供电 |
| 通信 | **Modbus RTU（RS-485）** / USB / Analog | 与 UR 直连 |

| 防护等级 | 工业级（非密封防尘防水） | 室内/洁净环境 |

## 3. 自适应指的工作原理

这是 2F-85 区别于普通平行夹爪的**核心机制**。

### 3.1 普通平行夹爪的局限

普通平行夹爪（如 Robotiq 2F-85 关闭「自适应」后的纯平行模式，或廉价电动夹爪）只有**一个自由度**——两指刚性平移：

- 只能在固定宽度间开合；
- 夹不规则物体时只有「两点接触」，力分布差，易滑脱；
- 对尺寸/形状变化敏感，每次换物体要重设行程。

### 3.2 2F-85 的自适应包络

2F-85 每根指分**两段（近节 + 远节）**，通过一个**被动铰链 + 连杆机构**连接：

```
   指尖（远节）─── 铰链 ─── 近节 ─── 驱动滑块
        │                          │
        └─ 接触物体后被动旋转，包络物体轮廓
```

- 夹持时，近节先接触物体侧面；
- 随着继续闭合，**远节绕铰链被动旋转**，从上方/对侧包住物体；
- 结果是**多点包络接触**（近节 + 远节同时接触），抓持稳定性远超两点平行夹持。

这使 2F-85 能用一个夹爪稳定抓取**圆柱、方块、球、不规则件**等多种形状，无需为每种物体换专用夹具——这正是它在通用操作任务里受欢迎的根本原因。

### 3.3 四种抓取模式

通过**旋转指段安装方向**，2F-85 可工作在四种模式：

| 模式 | 配置 | 典型用途 |
| --- | --- | --- |
| **基本模式（Basic）** | 两指同向，自适应包络 | 通用抓取（圆柱、方块） |
| **宽行程模式（Wide）** | 指段外翻，扩大有效开口 | 大物体/异形件 |
| **夹持/钳模式（Pinch）** | 指尖对捏（近节不参与） | 小件、精密捏取 |
| **剪刀模式（Scissor）** | 两指交叉如剪刀 | 特殊形状（少用） |

> 这相当于「一个夹爪顶四个用」，对研究里频繁切换物体类型的 IL/BC 数据采集极有价值。

## 4. 关键技术解析

### 4.1 力控与位置控的双模

2F-85 内置控制器支持：

- **位置控制**：指目标开合宽度（mm），到目标即停；
- **力控制**：闭合到接触物体后维持目标力（N），用于易碎/易变形物；
- **混合模式**：先快速闭合到接近物体，再切力控慢夹——兼顾速度与安全。

对 IL/BC 实验，通常用**力控闭合**采集「抓到即停」的演示，避免压碎物体或过抓。

### 4.2 物体检测（part detection）

夹爪能根据**位置-力曲线**判断是否抓到物体：

- 闭合过程中位置停在目标宽度前 → 抓到物体（success）；
- 闭合到位未遇阻力 → 未抓到（miss）。

这给上层策略一个**二元成功信号**（grip success），无需额外触觉传感器，简化了 IL 的奖励/标签。

### 4.3 电动 vs 气动

| 维度 | 2F-85（电动） | 气动夹爪 |
| --- | --- | --- |
| 气源需求 | 无 | 需压缩空气 |
| 力控可调性 | 强（数字设力/位） | 弱（靠调气压） |
| 速度 | 中（~0.4 s） | 快（<0.2 s） |
| 噪音 | 低 | 高（排气） |
| 重复精度 | 高 | 中 |
| 成本 | 中高 | 低 |

电动方案的研究友好性（数字接口、可编程力）使 2F-85 在实验室胜出；高速产线仍多用气动。

## 5. 控制接口与软件生态

### 5.1 通信与驱动

| 接口 | 说明 |
| --- | --- |
| **Modbus RTU（RS-485）** | 主接口，与 UR 控制器直连 |
| USB | PC 直连调试 |
| Analog / I/O | 简单开闭控制 |
| **URCaps** | UR 示教器内图形化插件，零代码 |
| ROS | `robotiq_2finger_grippers`（ROS1/ROS2） |
| Franka 集成 | 通过 RS-485 转 USB + 自定义节点 |

### 5.2 ROS / Python 控制

典型 ROS 话题/服务：

- Action `/robotiq_2f_85_controller/gripper_action`：目标宽度 + 速度 + 力；
- 服务 `/robotiq_2f_85_controller/open` `/close`：便捷开闭。

Python 侧（`robotiq_driver`）可设 `position_mm`、`speed_mm_s`、`force_N`。

### 5.3 与主流机械臂的兼容性

2F-85 是**兼容性最广**的夹爪之一：

| 机械臂 | 兼容方式 |
| --- | --- |
| **Universal Robots（UR5e 等）** | **URCaps 即插即用**，最丝滑 |
| **Franka Panda / FR3** | RS-485 转 USB + 社区节点，需自配法兰 |
| xArm / KUKA iiwa | 社区支持 |
| 人形 / 移动臂 | 可作为末端工具，需自行集成 |

这正是它成为研究「默认夹爪」的原因——换机械臂不用换夹爪。详见 [`../arms/ur5e.md`](../arms/ur5e.md) 与 [`../arms/franka-panda.md`](../arms/franka-panda.md)。

## 6. 应用场景

| 场景 | 为什么选 2F-85 |
| --- | --- |
| **IL/BC 数据采集（通用物体）** | 自适应指对形状鲁棒，一个夹爪抓多物 |
| **Pick-and-place（电商分拣）** | 5 kg 负载 + 力控，SKU 多样性高时省换型 |
| **机器看护（CNC 上下料）** | 电动免气源，UR + URCaps 即用 |
| **实验室自动化（移液/取样）** | 力控保护脆弱耗材 |
| **教学/竞赛** | 即插即用，学生上手快 |
| **人形/移动臂末端工具** | 轻量、数字接口，易集成 |

不擅长：超精密装配（需更高刚度/精度）、重载（>5 kg）、高速节拍（电动慢于气动）、柔顺/触觉密集任务（无指面触觉传感，需外接）。

## 7. 与同类对比

### 7.1 vs 普通平行夹爪（如 Robotiq 失能模式 / 廉价电动）

| 维度 | 2F-85（自适应） | 普通平行夹爪 |
| --- | --- | --- |
| 指段 | 两段铰接（包络） | 单段刚性（两点接触） |
| 形状鲁棒性 | **强** | 弱 |
| 力控 | 可调（20–235 N） | 多数无 |
| 物体检测 | 有 | 多数无 |
| 价格 | 中高 | 低 |
| 适用 | 通用/研究 | 单一物件/低成本 |

### 7.2 vs 灵巧手（Shadow Hand / Allegro / Figure 类人手）

| 维度 | 2F-85 | 灵巧手 |
| --- | --- | --- |
| DoF | 1（开合） | 16–24（每指多关节） |
| 操作能力 | 抓/放 | **捏/转/拧/ manipulate** |
| 控制难度 | 低 | **极高**（维度灾难） |
| 数据需求 | 少 | **海量** |
| 价格 | ~1–2 千美元 | 数万–十万美元 |
| 研究定位 | 通用抓取 baseline | 灵巧操作前沿 |

> 灵巧手是「**能力上限高但样本效率地狱**」，2F-85 是「**能力有限但即用且数据高效**」。多数 IL/BC 工作因数据成本仍选 2F-85。

### 7.3 vs Robotiq 2F-140（同族大行程）

| 维度 | 2F-85 | 2F-140 |
| --- | --- | --- |
| 行程 | 85 mm | **140 mm** |
| 负载 | 5 kg | 5 kg |
| 抓取力 | 20–235 N | 20–235 N |
| 适用 | 中小物体 | **更大物体/宽口抓取** |

> 需抓大物体（如箱盒）选 2F-140，否则 2F-85 更紧凑、对臂负载影响小。

### 7.4 vs 吸盘（vacuum gripper）

| 维度 | 2F-85 | 吸盘 |
| --- | --- | --- |
| 适用物面 | 任意（夹） | 光滑平整面（吸） |
| 多孔/透气物 | 可夹 | 难吸 |
| 力控 | 强 | 弱（真空度） |
| 速度 | 中 | 快 |

> 平面/光滑件（如玻璃、纸箱顶面）吸盘更快；异形/多孔件夹爪更稳。

## 8. 常见坑与实战经验

- **法兰与接口匹配**：换机械臂时注意末端法兰（UR/Franka 标准不同）与 RS-485 走线，常需定制转接件。
- **指段方向**：四种模式靠物理旋转指段实现，切换模式**必须断电重装**，不能软件切。
- **力档过冲**：高速闭合 + 高力档对脆物（水果、塑料件）易碎，建议先低速 + 低力试抓。
- **自重对负载的影响**：0.55 kg 在 Panda（3 kg）上要计入末端负载，剩余有效载荷变小。
- **指尖磨损**：金属指尖易滑，常贴橡胶或 3D 打印定制指尖增摩。
- **ROS 时间同步**：`gripper_action` 的反馈延迟要与臂控制环对齐，否则 IL 数据里夹爪状态错位。
- **Modbus 地址**：直接发 Modbus 指令时注意寄存器地址（位置/速度/力），不同固件版本可能有差异。

## 9. 在 IL/BC 里的典型用法

2F-85 在模仿学习里几乎成为**事实标准末端执行器**，典型约定：

- **观测**：夹爪宽度（mm）、夹爪力（N）、（可选）物体检测位。
- **动作**：目标宽度（连续值，0–85 mm）或二元开/关（离散）。
- **成功信号**：闭合到位前的位置停 → 抓到。

许多公开数据集（如 Open-X-Embodiment 子集、Robomimic、DROID）里的「gripper action」即对应此类夹爪的开合。详见 [`../../datasets/open-x-embodiment.md`](../../datasets/open-x-embodiment.md) 与 [`../../methods/imitation-learning.md`](../../methods/imitation-learning.md)。
