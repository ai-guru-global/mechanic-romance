## 3. 关键技术

### 3.1 FSD 技术迁移

Tesla 把 FSD（自动驾驶）的**端到端神经网络架构**直接搬到 Optimus：

```
FSD：8 摄像头 → BEV 感知 → 规划 → 控制
                ↓
Optimus：8 摄像头 → 3D 感知 → 全身控制 → 关节力矩
```

- **统一架构**：一套 FSD 代码同时训车 + 机器人
- **数据复用**：Tesla 车队采集的视觉数据 → 训练 Optimus 视觉
- **端到端神经网络**：从图像直接输出控制

> 这是 Optimus **最深的护城河**——别人没有 100 万车队的视觉数据。

### 3.2 自研关节执行器

| 关节类型 | 数量 | 设计 |
| --- | --- | --- |
| **旋转关节** | 14 | 永磁同步电机 + 谐波减速器 |
| **线性关节** | 14 | 滚珠丝杠 + 力矩电机 |
| **灵巧手关节** | 11 | 空心杯电机 + 微型齿轮 |

> Tesla 2023 AI Day 公开执行器设计，**自研胜过采购**——成本可控制在每关节 $50 以内。

### 3.3 纯视觉路线

Optimus **不依赖 LiDAR**，只用 8 路 RGB 相机 + FSD 视觉模型：

- 优势：成本低（vs 激光雷达 $5k+）
- 劣势：光照敏感、深度信息弱
- **取舍**：FSD 已验证纯视觉可行

## 6. 商业路径

### 6.1 Tesla 的算盘

```
短期（2024-2026）：自家工厂部署
  ├─ 电池工厂：分拣 + 装配
  ├─ 汽车工厂：搬运 + 检测
  └─ 数千台规模

中期（2026-2028）：对外销售
  ├─ 工业 B2B（工厂租赁 / 销售）
  └─ 单价 $3-5 万

长期（2028+）：消费市场
  ├─ 家庭服务（家政）
  └─ 单价 $2-3 万（百万台量级）
```

### 6.2 三大优势 + 三大风险

**优势**：
- **量产能力**（Tesla 工厂 + 供应链）
- **自研芯片**（Dojo + FSD SoC）
- **数据规模**（车队 + 工厂场景）

**风险**：
- **灵巧操作弱**（11-DoF 手 < 其他人形 16+ DoF）
- **AI 路线保守**（端到端 ≠ VLA 通用）
- **场景仍窄**（仅工厂搬运成熟）

## 7. 技术栈

### 7.1 软件栈

```
优化器层：
├─ 全身控制（WBC）—— 自研
├─ 步态规划 —— Tesla 自研
├─ 视觉感知 —— FSD（端到端 BEV）
└─ 任务规划 —— FSD 决策模块
硬件层：
├─ 自研 SoC + FSD 芯片
├─ 自研执行器（旋转 + 线性 + 灵巧手电机）
└─ 8 路相机 + IMU
```

### 7.2 训练 / 仿真

- **仿真器**：NVIDIA Isaac Sim（已确认使用）
- **训练数据**：Tesla 工厂采集 + 车队数据
- **算力**：Dojo + GPU 集群
