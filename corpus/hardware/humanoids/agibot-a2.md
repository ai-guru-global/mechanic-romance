# 智元机器人 AgiBot A2 / 灵犀 X1 · 国产人形新势力

> **智元机器人（AgiBot）** 2023 年成立、2024 年发布 **A2 双足人形**、**灵犀 X1** 开源双臂平台。**国产人形"造车新势力"代表**——背靠上海国资 + 比亚迪 + 阿里参投，2024 年估值 $10 亿，2025 年开始量产。

> 最后更新：2026-08

## 3. 关键技术

### 3.1 A2 技术栈

```
感知层：
├─ 4 路 RGBD 相机
├─ 2 路广角 + 鱼眼
├─ 触觉皮肤
└─ 6 麦克风阵列
         ↓
决策层：
├─ VLA 模型（自研 + Llama 3 + VLM）
├─ 步态规划（RL 训练）
└─ 任务规划（LLM 决策）
         ↓
控制层：
├─ 全身控制（40+ DoF）
├─ 步态控制（PPO 训）
└─ 手臂控制（IL 训）
         ↓
执行层：
├─ 5 指灵巧手（自研）
├─ 关节执行器（自研）
└─ 电池 + 散热
```
