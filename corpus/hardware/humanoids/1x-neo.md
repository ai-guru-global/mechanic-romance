## 3. 关键技术

### 3.1 安全设计（核心差异点）

1. **轻量级结构**（30 kg）
2. **柔顺关节**（SEA / 弹性驱动器）
3. **触觉皮肤覆盖**（背部 / 手臂 / 手部）
4. **软质外壳**（泡沫 + 织物）
5. **速度限制**（默认 4 km/h，远低于竞品）

> **1X 的安全策略是"低威胁 + 慢速度 + 软接触"**——这是家庭场景的"准入证"。

### 3.2 端到端 VLA

Neo 采用类似 Helix / Figure 的**端到端 VLA 路线**：

```
RGBD 图像 + 文本指令 → VLA 模型 → 全身动作
                         │
                         └─ 25-DoF 全身控制（含手）
```

- 无显式 System 1 / System 2 拆分（与 Figure 不同）
- 直接输出连续动作
- 云端推理大模型 + 端上执行小模型

### 3.3 数据采集

1. **Eve（轮式）阶段**：远程操作 + VR 示教
2. **Neo 阶段**：人手 + VR 示教 + VLM-as-Expert
3. **量产阶段**：家庭场景众包（用户授权后）

## 7. 技术栈

### 7.1 软件栈

```
云端 VLA：GPT-4V / 自研多模态模型
   ↓
策略推理（边缘 + 云端混合）
   ↓
全身运动控制（25-DoF）
   ├─ 双腿（12-DoF）
   ├─ 双臂（8-DoF）
   └─ 双手（10-DoF）
```

### 7.2 安全子系统

- 力矩限幅（每关节 < 30 N·m）
- 触觉皮肤（碰撞检测 < 10 ms）
- 紧急停止（硬件按钮 + 软件双重）
- 速度限制（自适应环境）

## 8. 风险与挑战

| 风险 | 原因 | 缓解 |
| --- | --- | --- |
| **家用场景太复杂** | 任务/物体/环境多样性 | 大模型 + 众包数据 |
| **安全标准严苛** | ISO 13482 / IEC 61508 | 多重安全设计 |
| **量产成本** | 30 kg 轻量化贵 | 规模化 + 自研关节 |
| **价格战** | Tesla / Figure 价格更低 | 差异化（家用 + 服务） |
| **VLA 不成熟** | 端到端尚有挑战 | 分阶段部署 |
