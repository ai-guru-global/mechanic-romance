# Figure 02 人形机器人（Figure AI）

> **一句话定位**：美国 Figure AI 公司的第二代通用人形机器人——以与 OpenAI 合作的「语音对话驱动机器人动作」、BMW Spartanburg 工厂落地与「工厂先行、家庭在后」的商业路径著称，是闭源商业人形的代表，与学术开源的 Unitree H1 形成鲜明对照。

> **最后更新：2026-08**
>
> **可信度声明**：Figure AI 对 Figure 02 的技术细节**披露有限且高度营销化**。本文明确区分【官方公布】与【外界推测/媒体报道】，对未确认参数标注「待核」。读者应以官方一手材料为准。

---

## 1. 概览

Figure 02 由 Figure AI（创始人 Brett Adcock，2022 年成立）于 2024 年 8 月发布，是 Figure 01（2023 年亮相）的后继机型。它的两个标志性事件使其成为最受关注的商业人形：

1. **OpenAI 合作 demo（2024）**：Figure 发布一段视频，展示机器人通过对话理解人类指令（「你能吃的东西」→递苹果），据称由 OpenAI 的多模态模型提供视觉-语言理解，Figure 自研神经网络提供动作。这是「**对话即控制（conversation as control）**」的代表性演示。
2. **BMW 工厂落地（2024–2025）**：Figure 02 在 BMW 美国 Spartanburg 工厂进行试点部署，执行车身车间内的物料搬运、抓取、插入等任务，是少数进入真实汽车产线的人形之一。

商业定位（官方表述）：**「先工厂，后家庭」**——先在结构化工业场景打磨可靠性与经济性，再逐步进入家庭等非结构化场景。这与 Tesla Optimus「直接面向消费」的叙事不同。

**重要前提**：Figure 02 不对学术研究公开发售，**没有公开 SDK / URDF / 关节级控制接口**。因此本文侧重其商业与技术叙事，而非（如 H1 那样的）操作指南。

## 3. 关键技术解析

### 3.1【官方】机载计算与感知

Figure 02 相对 Figure 01 的核心升级（官方强调）：

- **机载计算（onboard compute）**：把推理算力集成到机器人本体内，摆脱外接工作站。官方称基于 NVIDIA 平台，使机器人「自主」行动，不再依赖云端/外接 PC。
- **6 个机载摄像头**：构成 360° 视觉感知（头部、躯干两侧、背部等），用于导航与操作。
- **机载语音交互**：通过机载麦克风/扬声器与 OpenAI 模型联动，实现「听到-理解-行动-回应」闭环。

这是 Figure 02 demo「对话递苹果」的技术基础：**视觉理解 + 语言理解 + 动作执行 全在机上闭环**。

### 3.2【官方】与 OpenAI 的合作：对话即控制

2024 年 Figure 与 OpenAI 宣布合作（Figure 同时完成 6.75 亿美元融资，投资方含 OpenAI 创投、Microsoft、NVIDIA、Bezos 等）。合作要点（官方公布）：

- OpenAI 提供**多模态模型**（视觉 + 语言理解）；
- Figure 自研**神经网络策略**负责动作（low-level control）；
- 两层协同：OpenAI 模型把「给我能吃的东西」这类自然指令解析为「找到苹果→抓取→递给人类」的子目标，Figure 策略执行具体动作。

> 注意：这只是 demo 级展示。生产环境下的鲁棒性、延迟、成功率，官方未公布可复现指标。

### 3.3【官方】BMW 工厂落地

Figure 02 在 BMW Spartanburg 工厂（美国南卡）的车身车间进行试点，执行任务包括（官方/媒体）：

- 车身框架物料抓取与放置；
- 小件插入/装配辅助；
- 车间内自主导航移动。

意义：这是人形机器人**进入真实汽车产线**的少数案例之一（与之并列的有 Apptronik Apollo 在 Mercedes 的试点、Boston Dynamics Atlas 在 Hyundai 的探索）。它验证了「人形作为通用劳动力」在结构化工业场景的可行性，但**规模化与单位经济性仍待证**。

### 3.4【推测】灵巧手设计

Figure 02 的手部外观为**类人五指灵巧手**，但官方未公布 DoF、扭矩、传感器配置。外界（媒体/分析）推测：

- 每手约 16 DoF（量级）；
- 电动驱动，含触觉传感（外观可见指尖/掌部疑似传感器区域）；
- 设计目标是「人类级抓取多样性」。

> 这些均为**待核**的推测，不应作为可靠参数引用。

### 3.5【推测】视觉系统

除官方公布的「6 个机载摄像头」外，外界推测 Figure 02 可能还集成 IMU、关节力矩传感、（可能的）深度/触觉，但**官方未确认完整传感器清单**。

## 4. 控制接口与软件生态

**关键事实：Figure 02 没有公开 SDK、URDF 或关节级控制接口。**

| 维度 | 状态 |
| --- | --- |
| 公开 SDK | ❌ 无 |
| 公开 URDF/MJCF | ❌ 无 |
| 关节级实时控制 | ❌ 不对外开放 |
| 开发者社区 | ❌ 无公开社区 |
| 训练方法 | 【推测】大规模仿真 + 真机学习（Figure 提及「端到端神经网络」），细节未公开 |
| 与外部集成 | 通过商业合作（如 BMW、OpenAI）私有对接 |

这与 Unitree H1 的「开源全栈」形成根本对比。因此，**学术研究者无法在 Figure 02 上做实验**——这也是 H1 成为学术首选而 Figure 成为商业标杆的分工原因。

> Figure 自研的「AI 系统」据称包含视觉-语言-动作（VLA）式的端到端策略，但架构、数据、训练流程均未公开。详见 [`../../methods/vision-language-action.md`](../../methods/vision-language-action.md)。

## 5. 商业定位与路径

Figure 的官方叙事是「**通用人类劳动力（general-purpose humanoid workforce）**」，路径分阶段：

```
阶段 1（当前）：工厂试点（BMW 等）—— 结构化场景打磨可靠性
        │
阶段 2（中期）：更多工厂/仓储 —— 规模化与单位经济性
        │
阶段 3（长期）：家庭/服务 —— 非结构化场景，最终消费化
```

关键差异化叙事：

- **「工厂先行」**：与 Tesla「直接消费」叙事不同，Figure 认为工业场景更结构化、容错更高、ROI 更易算，适合先打磨。
- **对话即控制**：强调通过自然语言指挥机器人，降低使用门槛。
- **端到端 AI**：强调「端到端神经网络」而非传统控制工程。

> 这些是**商业叙事**，其技术实现细节与真实性能指标大多未公开。研究者应以批判视角对待营销话术。

## 8. 常见误解与风险提示

- **「Figure 02 = 完整 VLA 端到端」**：官方只说「端到端神经网络」，未公布是否真正单一模型。可能仍是分层（感知-规划-控制）架构，**勿过度解读营销**。
- **「续航 5 小时」**：未说明工况（静置？行走？操作？）。实际作业续航通常远低于宣传值，**待工况核**。
- **「DoF 41」等具体数值**：广泛流传但**非官方**，引用时必须标注「待核」。
- **「已大规模量产」**：截至 2026-08 仍为**试点/小批量**，非规模化量产。
- **「家庭即将到来」**：官方远期愿景，无明确时间表，工业落地尚在验证单位经济性。
