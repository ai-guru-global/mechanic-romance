# 宇树 Unitree G1 · 消费级人形（$1.6 万起）

> 宇树科技 2024-05 发布的**消费级 humanoid**——**基础版 $16,000 起**，是**目前最便宜的"完整人形机器人"**。定位"**开发者平台 + 教育 + 极客**"，与 H1（$90k）形成"**消费级 + 工业级**"两档。

> 最后更新：2026-08

## 2. 规格

| 参数 | G1 | 备注 |
| --- | --- | --- |
| **总自由度** | **23-43 DoF**（基础 23 / 旗舰 43） | 可选 |

## 3. 关键技术

### 3.1 低成本关节

| 关节 | 数量 | 设计 |
| --- | --- | --- |
| **旋转关节** | 14 | 自研低减速比谐波 |
| **腿部关节** | 12 | 高扭矩密度 |
| **手臂关节** | 6 | 高速响应 |
| **灵巧手** | 5-7 | 简化设计 |

> **宇树自研关节**——这是其"价格屠夫"能力的根源。

### 3.2 RL 训练栈

G1 行走/起身等动作基于 **Isaac Lab + PPO/SAC** 训练：

```
仿真（Isaac Lab） → 域随机化 → PPO 训练 → Sim-to-Real → 部署
```

- 宇树 2023-2024 公开 H1 的训练栈（"**宇树森林**"）
- 配套 LEJU 强化学习平台（云端）

### 3.3 开发者友好

- **ROS2** 集成
- **Python SDK** 完整
- **URDF** 开源
- **仿真器** 集成 Isaac Sim

## 4. 应用场景

### 4.1 开发者平台（主）

| 任务 | 状态 | 难度 |
| --- | --- | --- |
| **行走 + 跑步** | ✅ | 已稳定 |
| **跳舞** | ✅ | 复杂动作 |
| **起身（摔倒恢复）** | ✅ | 强大 |
| **简单抓取** | 🟡 | 受限于 3 指 |
| **VLA 集成** | 🟡 | 社区驱动 |
| **复杂家务** | ⚪ | 需开发 |

### 4.2 教育（次）

- 高校机器人课程（清华、上交、浙大等）
- 高中 STEM 教育（部分学校）
- 培训机构（宇树官方合作）

### 4.3 工业（弱）

- 不适合重负载（2 kg max）
- 不适合高精度（手部简化）
- 适合**轻搬运 / 巡检 / 简单装配**

## 7. 商业策略

### 7.1 宇树的"价格屠夫"逻辑

```
宇树四足 → 工业四足 → 消费四足（Go1 → Go2）
宇树人形 → 研究人形（H1）→ 消费人形（G1）→ 工业人形（计划中）
```

- **H1 → G1 价格降 5×**（$90k → $16k）
- 仿"汽车行业"：先发布高端研究版，再下放到消费级
- 借鉴大疆无人机路径：行业 → 消费 → 巩固行业

### 7.2 应用路径

```
Phase 1（2024-2025）：开发者 + 教育
  ├─ 个人开发者（极客、ROS 玩家）
  ├─ 高校（机器人课程、毕设）
  └─ 培训机构
  
Phase 2（2025-2026）：轻工业 + 服务
  ├─ 餐厅 / 酒店迎宾
  ├─ 巡检 / 安防
  └─ 物流分拣（轻载）
  
Phase 3（2026-2028）：家庭服务
  ├─ 陪伴对话
  ├─ 简单家务
  └─ 老人看护
```

## 8. 技术栈

### 8.1 软件栈

```
宇树 SDK（Python + C++）
   ↓
ROS2 / 自研中间件
   ↓
RL 控制（Isaac Lab 训练）
   ├─ 步态（PPO）
   ├─ 起身（PPO + Curriculum）
   └─ 手臂（IL 演示）
   ↓
硬件抽象层
   ├─ 关节驱动（自研通信）
   ├─ RealSense 视觉
   └─ 语音（4 麦克风）
```

### 8.2 训练 / 仿真

- **仿真器**：NVIDIA Isaac Sim（宇树官方使用）
- **训练**：Isaac Lab + PPO
- **云端平台**：LEJU（宇树子公司）

## 9. 风险与挑战

| 风险 | 原因 | 缓解 |
| --- | --- | --- |
| **3 指手能力弱** | 简化设计 | 高配版 5 指 |
| **电池续航** | 0.6 kWh 仅 2 h | 优化算法 |
| **VLA 不成熟** | 依赖社区 | 与 VLA 公司合作 |
| **竞争激烈** | Optimus / Figure 价格战 | 持续降价 + 差异化 |
| **开发者生态** | 需要第三方应用 | 开发者活动 + 比赛 |
