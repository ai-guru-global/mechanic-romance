# 概念层 · Concepts

> 具身智能领域的**基础概念**词典。一个概念一个文件，讲清定义、直觉、与之相关的方法和论文。
>
> 与 [`methods/`](../methods/) 的区别：这里收录的是**概念名词**（是什么），那里收录的是**具体方法/算法**（怎么做）。

---

## 命名

`概念英文名.md`（小写连字符），如 `embodied-ai.md`、`action-space.md`。

## 笔记结构

```markdown
# 概念名（中文 · English）

> 一句话定义。

## 直觉
## 形式化（如适用）
## 相关概念（互链）
## 代表方法 / 论文（链 methods/ 与 papers/）
```
