# 训练层 · Concepts / Training

> 具身智能策略的**学习范式**：从数据到策略的训练流程——预训练、微调、模仿学习、强化学习等。这里收录训练相关的**概念名词**（是什么），具体算法（PPO/SAC/BC/Diffusion Policy）见 [`../../methods/`](../../methods/)。

---

## 收录范围

- 训练范式（预训练-微调、自监督、元学习）
- 微调技术（LoRA、Adapter、少样本、持续学习）
- 数据与优化（数据配比、灾难性遗忘、课程学习）
- 学习信号（演示、奖励、自监督目标）

> 与 [`../../methods/`](../../methods/) 的区别：那里收录**具体算法**（怎么做，如 Diffusion Policy 的去噪过程），这里讲**训练概念**（是什么，如「微调」作为一种范式的定位与权衡）。
