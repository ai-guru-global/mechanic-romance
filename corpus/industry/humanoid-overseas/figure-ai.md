# Figure AI · 美国人形机器人公司图谱

> **一句话定位**：Figure AI 是美国最具资本号召力的通用人形机器人公司——以「工厂先行、家庭在后」的商业路径、自研端到端 VLA 大模型 Helix、与 BMW Spartanburg 工厂的真实产线落地著称；2025 年估值从 26 亿美元跃升至 **390 亿美元**，是闭源商业人形的全球标杆。

> **最后更新：2026-08**
>
> **可信度声明**：本文严格区分【官方公布】与【外界推测/媒体报道】。融资数据以公司公告为准；技术细节（DoF、扭矩、架构）部分为官方公开、部分为外界推测，对未确认项标注「待核」。行业信息时效性强，读者应以一手官方材料复核。

## 3. 技术路线：端到端 VLA + 自研大模型

Figure 的技术叙事经历了从「合作」到「自研」的关键转向：

### 3.1【官方】从 OpenAI 合作到自研 Helix（关键转折）

- **2024 年**：Figure 与 OpenAI 合作发布「对话递苹果」demo，OpenAI 提供多模态视觉-语言模型，Figure 自研神经网络提供动作。这段视频引爆了「**对话即控制（conversation as control）**」叙事。
- **2024 年中起**：Figure **终止与 OpenAI 的合作**（官方/媒体），转而自研端到端 VLA 大模型。
- **2025 年**：自研成果落地为 **Helix** 系列。

> 这是一个被外界低估的信号：Figure 选择「**大模型必须自研、与硬件深度耦合**」，与 Physical Intelligence「只做软件大脑、适配任意硬件」的路线形成根本分歧。

### 3.2【官方】Helix：Figure 的端到端 VLA 大模型

Helix 是 Figure 自研的 Vision-Language-Action 模型，分两代：

| 版本 | 能力 | 关键指标 | 来源 |
| --- | --- | --- | --- |
| **Helix 01** | 首个能对整个人形上半身（腕、躯干、头、每根手指）输出高频连续控制的 VLA | 约 200 Hz 控制频率 | 【官方】 |
| **Helix 02** | 单一神经系统直接从像素控制**全身**；支持行走、工具使用、双手协作、多机器人协作（无需预编程协调） | 全身一体化、长时程自主 | 【官方】 |

Helix 的设计目标（官方表述）：「像人一样推理」，把感知-运动-推理全闭环放在机载实时运行。在物流分拣场景，官方称 Helix 正「逼近人类水平的灵巧度与速度」。

> 注意：这些是**官方叙事**，生产环境的鲁棒性、成功率、泛化指标，Figure 未公布可复现的第三方基准。

### 3.3【推测】架构推断

基于 Helix 的能力描述，外界推测其架构属于当前 VLA 主流范式（详见 [`../../methods/vision-language-action.md`](../../methods/vision-language-action.md)）：

- 预训练 VLM 主干（继承互联网语义知识）+ 动作头（连续动作输出）；
- 大规模真机 + 仿真数据联合训练；
- 可能采用 flow matching / diffusion 风格的连续动作生成（与 Physical Intelligence π₀ 思路相近）。

> 这些架构细节**均未官方公布**，引用时必须标注「待核」。

## 4. 数据策略

Figure 的数据闭环是核心壁垒，但公开细节有限：

| 维度 | 状态 | 来源 |
| --- | --- | --- |
| 真机数据采集 | 大规模遥操作 + 自主采集（工厂内） | 【官方/媒体】 |

> Figure 的核心论点：**真实工业场景的数据回流**是训练可靠 VLA 的关键，而这一点只有「已经在工厂里跑」的公司才有——这是它相对纯软件公司的护城河叙事。

## 5. 落地场景

Figure 的官方路径是分阶段商业化：

```
阶段 1（当前）：工厂试点（BMW Spartanburg）—— 结构化场景打磨可靠性
        │
阶段 2（中期）：更多工厂/仓储 —— 规模化与单位经济性
        │
阶段 3（长期）：家庭/服务 —— 非结构化场景，最终消费化
```

### BMW Spartanburg 落地时间线（官方）

| 时间 | 里程碑 |
| --- | --- |
| 2023-11 | 与 BMW 签署商业合作协议 |
| 2024-10 | Figure 02 开始在 BMW 处理钣金件 |
| 2025（全年） | Figure 02 协助生产 **超 30,000 辆 BMW X3**（Spartanburg） |
| 2025-09-18 | Figure 03 进入 BMW Hall 52（装配与物流车间），由 Helix 02 驱动，执行零件分拣、上料、复杂物流任务 |

| 场景 | 状态 |
| --- | --- |
| 汽车工厂物料搬运 / 零件分拣 / 上料 | 【官方落地】BMW |
| 车间自主导航 | 【官方落地】 |
| 对话驱动抓取/递送 | 【官方 demo】，非量产指标 |
| 仓储/物流 | 【规划/推进中】 |
| 家庭服务 | 【长期愿景】无时间表 |
| 学术研究 | ❌ 不可得（不公开发售、无开源接口） |

> 意义：Figure 是少数**进入真实汽车产线**的人形之一（并列的有 Apptronik Apollo 在 Mercedes、Boston Dynamics Atlas 在 Hyundai 的探索）。它验证了「人形作为通用劳动力」在结构化工业场景的可行性，但**规模化与单位经济性仍待证**。

## 9. 风险与争议

- **估值过热质疑**：390 亿美元估值对应实际出货量仍为试点/小批量（非规模化量产），单位经济性未证实，多家分析机构质疑泡沫。
- **「端到端 VLA」营销话术**：官方称「单一神经系统控制全身」，但是否真正单一模型、生产环境成功率多少，均未公布可复现指标，**勿过度解读**。
- **「续航 5 小时」**：未说明工况（静置/行走/操作），实际作业续航通常远低于宣传值，**待工况核**。
- **DoF / 扭矩等具体数值**：广泛流传的「41 DoF」等**非官方**，引用必须标注「待核」。
- **家庭愿景时间表**：官方远期目标，工业落地尚在验证单位经济性，家庭化无明确时间表。
- **对 OpenAI 分手的影响**：自研 Helix 能否真正替代 OpenAI 的多模态能力，外界仍在观察。
