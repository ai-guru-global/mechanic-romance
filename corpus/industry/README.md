## 2024–2026 行业关键判断

1. **人形机器人竞赛白热化**：Figure、Tesla、宇树、智元等数十家涌入，资本高度集中。
2. **具身大模型公司崛起**：Physical Intelligence（π₀）、Skild 等专注「机器人大脑」，与硬件解耦。
3. **数据成为新瓶颈**：硬件趋同后，谁掌握大规模高质量真机数据，谁赢。
4. **国产供应链成熟**：谐波减速器（绿的）、伺服（汇川）、六维力矩传感器（坤维）已可替代进口。

## 分析维度

每家公司/产品的笔记建议覆盖：
- **技术路线**：端到端 VLA？分层控制？传统运动学？
- **硬件参数**：DoF、负载、身高、续航。
- **数据策略**：自采？遥操？仿真？
- **落地场景**：工厂装配？仓储物流？家庭服务？
- **融资/估值/进度**：截至记录日期。
- **公开 Demo 水平**：是遥控还是自主？泛化如何？

> ⚠️ 行业信息时效性强，所有笔记顶部须标注**「最后更新日期」**，并区分「官方公布」与「外界推测」。
