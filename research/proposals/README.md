# 选题与立项 · Proposals

记录课题的**研究问题、选题论证、立项文档**。每个研究方向 / 选题一个文件。

---

## 文件命名

`YYYY-NN-关键词.md`（序号区分同期选题），如 `2026-01-vla-fine-tuning.md`。

---

## 结构建议

```markdown
# 选题标题

## 背景与动机
为什么值得做？现有工作缺什么？

## 研究问题
明确列出 1-3 个可回答的问题。

## 假设
预期答案 / 解决思路。

## 相关工作
引用 corpus/papers/ 中的笔记。

## 可行性
数据、算力、时间、风险。

## 预期产出
论文 / Demo / 场景。

## 决策
立项 / 暂缓 / 放弃，及理由。
```
