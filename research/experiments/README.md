# 实验记录 · Experiments

记录**可复现**的实验：配置、超参、环境、结果、分析。一次实验一个文件。

---

## 文件命名

`YYYY-MM-DD-关键词.md`，如 `2026-08-05-dp-lr-ablation.md`。

---

## 记录模板

```markdown
# 实验标题

## 目的
要验证什么假设？

## 环境
- 硬件（GPU/机器人本体）
- 软件（框架/版本/commit）
- 数据（来源 + 预处理）

## 配置
关键超参表。

## 过程
命令、随机种子、异常。

## 结果
指标表 / 图（图放 demo/assets/ 或专门目录）。

## 分析
结论、意外发现、下一步。
```

> ⚠️ **大文件不入库**：模型权重、原始数据见 [`.gitignore`](../../.gitignore)，实验中只保留配置与结论，大文件注明外部存储路径。
